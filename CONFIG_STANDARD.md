# Средняя конфигурация: Стандартный набор модулей (20 модулей)

## Назначение
Расширенный функциональный набор для профессиональной обработки данных. Включает все базовые модули + специализированные инструменты.

**Базовая конфигурация (7 модулей)** + **Расширения (13 модулей)** = **20 модулей**

---

## БАЗОВЫЕ МОДУЛИ (из минимальной конфигурации)

1. Загрузка файлов
2. Чтение текстовых файлов
3. Фильтрация и поиск
4. Извлечение данных (Pattern Extraction)
5. Базовая статистика
6. Конвертация форматов
7. Экспорт результатов

---

## РАСШИРЕННЫЕ МОДУЛИ (13 новых)

## МОДУЛЬ 8: Работа с PDF
**Категория**: Специализированная обработка
**Приоритет**: Высокий

### Ввод
- **Форматы**: PDF
- **Параметры**:
  - Диапазон страниц
  - Режим извлечения (текст/таблицы/изображения)

### Обработка
- Извлечение текста из PDF
- Извлечение таблиц
- Извлечение изображений
- Получение метаданных PDF
- Разделение PDF на страницы

### Вывод
- **Текст**: TXT, MD, JSON
- **Таблицы**: CSV, JSON, Excel
- **Изображения**: PNG, JPG
- **Метаданные**: JSON

---

## МОДУЛЬ 9: Работа с Excel
**Категория**: Ввод/Вывод
**Приоритет**: Высокий

### Ввод
- **Форматы**: XLS, XLSX, ODS
- **Параметры**:
  - Выбор листа
  - Диапазон ячеек
  - Заголовки (строка с названиями колонок)

### Обработка
- Чтение всех листов
- Чтение конкретного листа
- Чтение диапазона ячеек
- Определение типов данных

### Вывод
- **Форматы**: CSV, JSON, HTML (таблица)
- **Метаданные**: Список листов, размеры таблиц

---

## МОДУЛЬ 10: Очистка и нормализация текста
**Категория**: Текстовая обработка
**Приоритет**: Средний

### Ввод
- **Форматы**: TXT, CSV, JSON
- **Параметры**:
  - Операции очистки (чекбоксы)

### Обработка
- Удаление лишних пробелов
- Удаление HTML-тегов
- Удаление спецсимволов
- Приведение к нижнему/верхнему регистру
- Удаление дубликатов строк
- Удаление пустых строк
- Удаление стоп-слов (для разных языков)

### Вывод
- **Форматы**: TXT, CSV, JSON
- **Метрики**: Количество удалённых элементов

---

## МОДУЛЬ 11: Сортировка и группировка
**Категория**: Трансформация данных
**Приоритет**: Средний

### Ввод
- **Форматы**: CSV, JSON, JSONL
- **Параметры**:
  - Поле для сортировки
  - Порядок (asc/desc)
  - Поле для группировки

### Обработка
- Сортировка по одному/нескольким полям
- Группировка по значениям поля
- Подсчёт элементов в группах
- Агрегация (sum, avg, count, min, max)

### Вывод
- **Форматы**: CSV, JSON
- **Визуализация**: Сгруппированные данные с метриками

---

## МОДУЛЬ 12: Слияние данных (Join)
**Категория**: Трансформация данных
**Приоритет**: Средний

### Ввод
- **Форматы**: CSV, JSON (2+ файла)
- **Параметры**:
  - Ключевое поле для объединения
  - Тип join (inner, left, right, outer)

### Обработка
- Inner join (пересечение)
- Left join (все из левого + совпадения)
- Right join (все из правого + совпадения)
- Full outer join (всё)
- Объединение по нескольким полям

### Вывод
- **Форматы**: CSV, JSON
- **Метрики**: Количество объединённых записей

---

## МОДУЛЬ 13: Валидация данных
**Категория**: Обогащение данных
**Приоритет**: Средний

### Ввод
- **Форматы**: CSV, JSON
- **Параметры**:
  - Правила валидации (схема)
  - Поля для проверки

### Обработка
- Проверка типов данных
- Проверка на обязательные поля
- Проверка email-адресов
- Проверка URL
- Проверка дат (формат)
- Проверка числовых диапазонов
- Кастомные regex-правила

### Вывод
- **Отчёт о валидации**: JSON, HTML
- **Невалидные данные**: CSV, JSON (отдельно)
- **Валидные данные**: CSV, JSON (отдельно)
- **Метрики**: Процент успешной валидации

---

## МОДУЛЬ 14: Дедупликация
**Категория**: Обогащение данных
**Приоритет**: Средний

### Ввод
- **Форматы**: CSV, JSON, TXT
- **Параметры**:
  - Поля для сравнения (для структурированных данных)
  - Режим: точное совпадение / fuzzy match

### Обработка
- Удаление точных дубликатов
- Удаление похожих записей (fuzzy matching)
- Группировка дубликатов (показать все варианты)
- Выбор стратегии (какую запись оставить)

### Вывод
- **Уникальные данные**: CSV, JSON, TXT
- **Удалённые дубликаты**: CSV, JSON (лог)
- **Метрики**: Количество дубликатов, процент уникальности

---

## МОДУЛЬ 15: Разделение текста
**Категория**: Текстовая обработка
**Приоритет**: Низкий

### Ввод
- **Форматы**: TXT, MD
- **Параметры**:
  - Разделитель (символ, regex, количество строк)
  - Режим разделения

### Обработка
- Разделение по символу/строке
- Разделение по regex-паттерну
- Разделение на N частей равного размера
- Разделение на части по N строк

### Вывод
- **Форматы**: Несколько TXT файлов, ZIP архив
- **Структурированный**: JSON (массив частей)

---

## МОДУЛЬ 16: Объединение файлов
**Категория**: Трансформация данных
**Приоритет**: Средний

### Ввод
- **Форматы**: TXT, CSV, JSON (несколько файлов)
- **Параметры**:
  - Порядок объединения
  - Разделитель между файлами

### Обработка
- Конкатенация текстовых файлов
- Слияние CSV (с общими колонками)
- Слияние JSON (массивы/объекты)
- Добавление разделителей между файлами

### Вывод
- **Форматы**: TXT, CSV, JSON (объединённый файл)
- **Метрики**: Общий размер, количество объединённых файлов

## Технические характеристики

**Количество модулей**: 20
**Сложность реализации**: Средняя
**Время разработки**: 6-8 недель
**Подходит для**: Бизнес-приложения, аналитика, ETL-процессы

**Зависимости**:
- PDF библиотеки (PyPDF2, pdfplumber)

- Fuzzy matching (fuzzywuzzy)

**Преимущества над минимальной конфигурацией**:
- Работа с PDF и Excel
- Продвинутая обработка данных (join, group, validate)
- Визуализация результатов
- Генерация отчётов
- Парсинг HTML/XML
